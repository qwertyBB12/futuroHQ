Create `scripts/ingest-transcripts.ts` that:

1. **Sanity client setup** — same pattern as `batch-enrich.ts`:
   ```typescript
   import { createClient } from '@sanity/client'
   const client = createClient({
     projectId: 'fo6n8ceo',
     dataset: 'production',
     apiVersion: '2024-01-01',
     token: process.env.SANITY_TOKEN,
     useCdn: false,
   })
   ```

2. **CLI flags**: `--dry-run` (default, preview only) and `--live` (actually patch). Print mode at start.

3. **Fetch all B2 video documents** via GROQ:
   ```typescript
   const videos = await client.fetch(`*[_type == "video" && videoSource == "b2"]{ _id, title, b2Key, fullText }`)
   ```

4. **For each video with a b2Key**, derive the transcript filename:
   - Extract the filename stem from b2Key: `b2Key.split('/').pop().replace('.mp4', '')`
   - Look for `transcripts/{stem}.enriched.json` on disk
   - Read and parse the JSON file

5. **Skip if fullText already populated** (idempotent). Print skip message.

6. **Build patch payload** from enriched JSON:
   ```typescript
   const patch = {
     fullText: enriched.full_text,
     speakerSegments: enriched.speaker_segments.map((seg, i) => ({
       _type: 'object',
       _key: `seg-${i}`,
       speaker: seg.speaker,
       start: seg.start,
       end: seg.end,
       text: seg.text,
     })),
   }
   ```
   Also patch `duration` from `enriched.duration_seconds` if available.

7. **In --live mode**, execute Sanity patch:
   ```typescript
   await client.patch(video._id).set(patch).commit()
   ```

8. **Summary**: Print totals (patched, skipped, errors, missing transcript file).

9. **Error handling**: Try/catch per document, continue on failure, collect errors for final report.

Important: The enriched JSON `speaker_segments` array items do NOT have `_key` or `_type` — these must be added when building the Sanity patch (Sanity arrays require `_key` on each item and `_type: 'object'` for anonymous objects).

Use `npx tsx scripts/ingest-transcripts.ts --dry-run` to run.
