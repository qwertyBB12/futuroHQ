Create `scripts/ingest-transcripts.ts` following the batch-enrich.ts pattern (dotenv, createClient, processInChunks helper, --dry-run flag, CLI usage banner).

The script does:

1. **Fetch all video documents** with `videoSource == "b2"` that have a `b2Key` set. GROQ query:
   `*[_type == "video" && videoSource == "b2" && defined(b2Key)]{_id, b2Key, title, fullText}`
   Note: These are drafts, so query must NOT exclude drafts. Use `!(_id in path("drafts.**"))` = false, or simply omit that filter.

2. **Scan transcripts/ directory** for all `*.enriched.json` files.

3. **Match logic:** For each video doc, extract the filename stem from `b2Key` (the last path segment without extension). Example: b2Key = `"Futuro MMXIX/edited/HB_ALISTAIR_ahq12.mp4"` -> stem = `"HB_ALISTAIR_ahq12"`. Find the matching `{stem}.enriched.json` in the transcripts directory.

4. **For each match**, read the enriched JSON and extract:
   - `full_text` -> patches `fullText` field on the video doc
   - `speaker_segments` array -> patches `speakerSegments` field, but each item needs `_key` (use crypto.randomUUID().slice(0,8)) and `_type: 'object'` added for Sanity array items. Map fields: `speaker`, `start`, `end`, `text`.

5. **Patch using client.patch(docId).set({fullText, speakerSegments}).commit()** — use `set` not `setIfMissing` since we want to overwrite any existing transcript data with the latest pipeline output. Process in chunks of 10 with 1s delay.

6. **Report:** Print matched count, unmatched count, already-has-transcript count (skip if `--force` not passed and fullText already populated). List any unmatched videos (have b2Key but no matching enriched JSON) and unmatched enriched files (no corresponding video doc).

7. **Import path:** Use `import {resolve, basename} from 'path'` and `import {readFileSync, readdirSync} from 'fs'`. Transcripts dir: `resolve(__dirname, '../transcripts')`.

Usage: `npx tsx scripts/ingest-transcripts.ts [--dry-run] [--force]`

Important: The enriched JSON `speaker_segments` items have `{speaker, start, end, text}` — these map directly to the transcriptBlock schema fields. Add `_key` and `_type: 'object'` to each before patching.
