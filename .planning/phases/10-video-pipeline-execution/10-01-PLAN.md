     projectId: 'fo6n8ceo',

   })

2. **CLI flags**: `--dry-run` (default, preview only) and `--live` (actually patch). Print mode at start.

3. **Fetch all B2 video documents** via GROQ:
   ```typescript
   const videos = await client.fetch(`*[_type == "video" && videoSource == "b2"]{ _id, title, b2Key, fullText }`)
   ```

4. **Pre-flight cross-reference step (CRITICAL)** — Before any mutations, list all b2Key filename stems from the fetched videos and cross-reference against files in the `transcripts/` directory:
   ```typescript
   // For each video, derive expected transcript filename
   const stem = b2Key.split('/').pop().replace('.mp4', '')
   const expectedPath = `transcripts/${stem}.enriched.json`
   // Check if file exists on disk
   ```
   Print a summary table of all b2Key stems with matched/unmatched status. If any stems have no matching `.enriched.json`, print them clearly as warnings (e.g., "WARNING: No transcript file for b2Key stem 'XYZ' — will be skipped during ingestion"). This surfaces gaps before --live mode runs, rather than silently reporting "missing transcript file" per document.

5. **For each video with a b2Key**, derive the transcript filename:
   - Extract the filename stem from b2Key: `b2Key.split('/').pop().replace('.mp4', '')`
   - Look for `transcripts/{stem}.enriched.json` on disk
   - Read and parse the JSON file

6. **Skip if fullText already populated** (idempotent). Print skip message.

7. **Build patch payload** from enriched JSON:
   ```typescript
   const patch = {
     fullText: enriched.full_text,
     speakerSegments: enriched.speaker_segments.map((seg, i) => ({
       _type: 'object',
       _key: `seg-${i}`,
       speaker: seg.speaker,
       start: seg.start,
       end: seg.end,
       text: seg.text,
     })),
   }
   ```
   Also patch `duration` from `enriched.duration_seconds` if available.

8. **In --live mode**, execute Sanity patch:
   ```typescript
   await client.patch(video._id).set(patch).commit()
   ```

9. **Summary**: Print totals (patched, skipped, errors, missing transcript file).

10. **Error handling**: Try/catch per document, continue on failure, collect errors for final report.

Important: The enriched JSON `speaker_segments` array items do NOT have `_key` or `_type` — these must be added when building the Sanity patch (Sanity arrays require `_key` on each item and `_type: 'object'` for anonymous objects).

Use `npx tsx scripts/ingest-transcripts.ts --dry-run` to run.

   - `b2Key` — must be non-empty string
   - `cdnUrl` — must be non-empty string, must match pattern `https://benext.b-cdn.net/{b2Key}` (with spaces URL-encoded as %20)
   - `thumbnailUrl` — must be non-empty string; if missing, compute as `https://benext.b-cdn.net/{b2Key}` (same CDN base — per VPIPE-01, thumbnailUrl should be populated when missing)
   - `bunnyStatus` — must be "ready"
   - `resolution` — report if missing; patch from video metadata if available in doc, but do not fail if absent

5. **If cdnUrl is missing or incorrect**, compute it:
   ```typescript
   const CDN_BASE = 'https://benext.b-cdn.net'
   const expectedCdnUrl = `${CDN_BASE}/${b2Key.replace(/ /g, '%20')}`
   ```

6. **If thumbnailUrl is missing**, compute it (per VPIPE-01):
   ```typescript
   // thumbnailUrl follows same CDN pattern as cdnUrl
   const expectedThumbnailUrl = `${CDN_BASE}/${b2Key.replace(/ /g, '%20')}`
   ```
   Note: This sets thumbnailUrl to the video CDN URL as a fallback. If a dedicated thumbnail image exists at a different path, it should be set manually or by a future script.

7. **Build patch** only for fields that are missing or incorrect. Skip if all fields valid.

8. **In --live mode**, execute patch. In --dry-run, print what would change.

9. **Summary report**:
   - Total B2 videos
   - Already complete (all fields valid)
   - Patched (fields were missing/wrong)
   - Missing b2Key (cannot compute CDN URL — flag as error)
   - Missing thumbnailUrl (count patched)
   - Missing resolution (count, informational only)

10. **Verify-only mode** (`--verify-only`): Print a table of all B2 videos with field status (checkmark/x for each field: b2Key, cdnUrl, thumbnailUrl, resolution, bunnyStatus). No patches attempted. Exit code 1 if any video is incomplete, 0 if all complete.
