# Phase 11: Video Metadata Completion - Context

**Gathered:** 2026-03-26
**Status:** Ready for planning

<domain>
## Phase Boundary

Populate missing metadata on all video documents: auto-generate descriptions from transcript text, assign tags from existing taxonomy, and ensure thumbnails are present. No video should have content gaps in description, tags, or thumbnail after this phase. Studio-side only — no frontend changes.

</domain>

<decisions>
## Implementation Decisions

### Description Generation
- **D-01:** Use Claude API to summarize fullText transcripts into 2-3 sentence descriptions for videos missing them. Script should batch-process, support --dry-run, and show generated text for review before patching.
- **D-02:** Use `client.patch().set()` (consistent with Phase 10 decision) — always overwrite with latest generated description unless video already has a manually-written one (use --force to override existing).

### Tag Assignment
- **D-03:** Match transcript content against existing tag taxonomy labels (query all `tag` documents, match by keyword presence in fullText). Do NOT create new tags — only assign from existing taxonomy.
- **D-04:** Assign tags as references to tag documents (consistent with consolidated tags_ref → tags migration from v1.0).

### Thumbnail Strategy
- **D-05:** Completeness config should accept EITHER `thumbnailUrl` (CDN, from Bunny pipeline) OR `thumbnailImage` (Sanity image upload) as satisfying the thumbnail requirement. Currently only checks `thumbnailImage.asset._ref`.
- **D-06:** For B2 videos, `thumbnailUrl` is the primary source (auto-generated by pipeline). Script should verify thumbnailUrl exists on all 26 B2 videos and flag any missing.

### Batch Script Design
- **D-07:** Single script (`scripts/enrich-video-metadata.ts`) with subcommands: `descriptions`, `tags`, `thumbnails`, `all`. Follows ingest-transcripts.ts pattern (CLI flags, chunked processing, dry-run, Sanity client setup).
- **D-08:** All operations support --dry-run for preview and --force to overwrite existing values.

### Claude's Discretion
- Prompt engineering for description summarization (length, tone, structure) — Claude can determine the optimal prompt based on transcript content
- Tag matching threshold (exact vs fuzzy keyword matching) — Claude can decide the matching strategy
- Script chunk size and rate limiting — follow existing pattern (10 per chunk, 1s delay)

</decisions>
