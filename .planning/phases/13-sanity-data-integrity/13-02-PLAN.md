**Functions:**

1. `load_audit_results(path: str|Path) -> dict` — `json.load(open(path))`, validates it has "failures" and "summary" keys.

2. `build_fix_plan(audit_data: dict) -> list[dict]` — iterates `audit_data["failures"]`, for each:
   - If `"wrong_person_tags"` in issues: create `{"doc_id": ..., "patches": {"featuredIn": []}, "action": "clear_featured_in"}` (per D-09, clears wrong refs).
   - If `"cdnurl_formula_mismatch"` in issues: create `{"doc_id": ..., "patches": {"cdnUrl": CDN_BASE + "/" + doc["b2Key"].replace(" ", "%20")}, "action": "fix_cdnurl"}`.
   - If `"b2_not_found"` in issues: create `{"doc_id": ..., "patches": None, "action": "flag_b2_missing", "note": "File not in B2 — manual investigation required"}`.
   - Skip `manual_review` items entirely (per D-08 — no auto-patching, just reporting).
   - Returns list of fix actions.

3. `patch_sanity_document(doc_id: str, patches: dict, dry_run: bool = True) -> bool` — same pattern as populate-sanity-videos.py:
   ```python
   if dry_run:
       print(f"  [DRY RUN] Would patch {doc_id}: {list(patches.keys())}")
       return True
   mutations = {"mutations": [{"patch": {"id": doc_id, "set": patches}}]}
   # curl POST to SANITY_API/data/mutate/SANITY_DATASET with auth
   ```

4. `apply_fixes(fix_plan: list, dry_run: bool = True) -> dict` — iterates fix_plan:
   - For items with `patches is not None`: call `patch_sanity_document(doc_id, patches, dry_run)`.
   - For items with `patches is None` (flags): print warning, skip.
   - Rate limit: sleep 0.5s every 25 patches (per research: Sanity free tier ~100 req/s).
   - Returns `{"applied": N, "skipped": N, "failed": N}`.

6. Apply fixes (dry_run = not args.live)
7. Print results: applied/skipped/failed counts
8. If `--live`: print "Re-run audit to verify: python3 scripts/audit-sanity-integrity.py"
