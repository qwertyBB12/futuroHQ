   - cdnUrl == `CDN_BASE + "/" + b2Key.replace(" ", "%20")` (if not: issue `"cdnurl_formula_mismatch"`)
   - Returns `{"doc_id": doc["_id"], "b2_exists": bool, "cdn_formula_ok": bool, "issues": [...]}`
   - Note per D-01: HTTP 200/content-type/content-length checks deferred (Bunny CDN 401 blocker)

   - If found, loads JSON and returns the `named_speakers` dict (e.g., `{"SPEAKER_00": "Laura Miller"}` or `{}`)
   - If file not found, returns empty dict
   - This is the D-07 cross-reference step: reading actual diarization output to verify speaker identification

   - Call `load_enriched_speakers(stem, enriched_dir)` to read the corresponding enriched JSON
   - If `named_speakers` is empty (no name-to-person mapping available): the current featuredIn refs are unverifiable.    Returns `{"doc_id": doc["_id"], "issues": [...], "action": str|None, "reason": str|None}`
