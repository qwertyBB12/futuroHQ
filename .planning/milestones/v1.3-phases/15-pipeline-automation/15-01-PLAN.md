    1. The script already has `if __name__ == "__main__": main()` so it works standalone. The issue is that `process_video()` does download + encode + transcribe + upload all in one function, and the upload path is hardcoded with `/raw/` to `/edited/` replacement. For the orchestrator, we need `process_video()` to RETURN the result (paths, metadata) instead of just printing. Modify `process_video()` to:
       - Return a dict with keys: `stem`, `processed_path` (Path to local processed file), `enriched_path` (Path to enriched JSON if transcribed), `edited_b2_path` (the B2 upload path), `upload_success` (bool), `duration`, `speakers`, `orig_size_mb`, `proc_size_mb`. Return `None` on failure.
       - Keep all existing print statements and behavior intact.
       - Add an optional `skip_upload=False` parameter. When True, skip the B2 upload step and set `upload_success=None`. When False, upload as before.
       - Add an optional `skip_cleanup=False` parameter. When True, do NOT delete `processed_path` and `video_path` at the end. The orchestrator needs the processed file for clip extraction.
       - The `if output_file.exists()` early-return should return a dict with `stem` and `skipped=True` instead of bare `return`.

    **Step C — Create scripts/pipeline.py orchestrator (per D-01, D-02, D-03):**

    ```python
    #!/usr/bin/env python3
    """
    End-to-end video pipeline orchestrator.
    Raw video -> encode + LUT -> transcribe -> diarize -> extract clips -> upload to B2 -> create Sanity docs.

    Usage:
        python3 scripts/pipeline.py "Futuro MMXXV/raw/card-1/Day 1/C3460.MP4"
        python3 scripts/pipeline.py "Futuro MMXXV/raw/card-1/Day 1" --camera canon-r5-clog3
        python3 scripts/pipeline.py "path" --skip-upload        # local only
        python3 scripts/pipeline.py "path" --skip-sanity         # upload but no Sanity docs
        python3 scripts/pipeline.py "path" --dry-run             # preview Sanity mutations
        python3 scripts/pipeline.py "path" --live                # execute Sanity mutations
    """
    ```

    Core structure:
    1. `parse_pipeline_args(argv=None)` — argparse with:
       - positional `b2_path` (raw video or folder B2 path)
       - `--camera` (choices from CAMERA_LUTS, default sony-a6700-slog3)
       - `--anamorphic` (store_true)
       - `--skip-transcribe` (store_true)
       - `--skip-upload` (store_true — local processing only, no B2 upload)
       - `--skip-sanity` (store_true — upload but don't create Sanity docs)
       - `--skip-clips` (store_true — encode+transcribe but skip clip extraction)
       - `--dry-run` (preview Sanity mutations)
       - `--live` (execute Sanity mutations)
       Default: no Sanity mutations (need explicit --dry-run or --live)

    2. `derive_b2_upload_path(raw_b2_path: str) -> str` — Convert raw path to edited path:
       - Replace `/raw/` with `/edited/` in the path
       - Replace original filename with `{stem}_processed.mp4`
       - Example: `Futuro MMXXV/raw/card-1/Day 1/C3460.MP4` -> `Futuro MMXXV/edited/card-1/Day 1/C3460_processed.mp4`

    3. `derive_clips_b2_path(stem: str, clip_filename: str) -> str` — Per D-06:
       - Return `Futuro MMXXV/clips/{stem}/{clip_filename}`
       - Example: `derive_clips_b2_path("C3460", "SPEAKER_00_00m00s-00m30s.mp4")` -> `Futuro MMXXV/clips/C3460/SPEAKER_00_00m00s-00m30s.mp4`

    4. `derive_cdn_url(b2_path: str) -> str`:
       - Return `https://benext.b-cdn.net/{b2_path}` with spaces URL-encoded to `%20`

    5. `upload_clips_to_b2(stem: str, clips_dir: Path) -> list[dict]` — Per D-06:
       - Read manifest.json from `clips_dir/{stem}/manifest.json`
       - For each clip in manifest["clips"], upload `clips_dir/{stem}/{clip["file"]}` to B2 at `derive_clips_b2_path(stem, clip["file"])`
       - Update each clip dict with `cdn_url` = `derive_cdn_url(clips_b2_path)` and `b2_key` = clips_b2_path
       - Return updated clips list
       - Per AUTO-02: reads filenames from manifest, no hardcoded speaker numbering

    6. `run_pipeline(b2_path: str, args: Namespace) -> dict` — Single file pipeline:
       - Step 1: Call `process_video(b2_path, camera=args.camera, anamorphic=args.anamorphic, skip_transcribe=args.skip_transcribe, skip_upload=args.skip_upload, skip_cleanup=True)` — returns result dict
       - Step 2: If not skip_transcribe and not skip_clips: Call `process_transcript(stem, video_path=result["processed_path"])` — extracts clips locally
       - Step 3: If not skip_upload: Upload processed video to B2 (already done in process_video unless skip_upload was True). Upload clips via `upload_clips_to_b2(stem, CLIPS_DIR)`.
       - Step 4: Clean up local temp files (processed video, raw download)
       - Return result dict with all metadata (b2_paths, cdn_urls, clips info)
       - Per D-13: On failure at any step, print which step failed + what completed. Return partial result with error info.

    7. `main()`:
       - Parse args
       - Import process-raw-video and extract-speaker-clips via importlib
       - Single file vs folder detection (same logic as process-raw-video.py: check if path ends with video extension)
       - Single file: call `run_pipeline()`
       - Folder (D-02): call `list_videos()` then `run_pipeline()` for each
       - Per D-14: batch mode logs failures, continues with remaining files, prints summary at end
       - Per D-15: no checkpoint state file — user re-runs with skip flags to resume
